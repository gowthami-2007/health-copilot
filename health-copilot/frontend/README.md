# Health Copilot — Frontend Application

React 18 + Vite client for the Personal Health Copilot web application.

## Scripts
- `npm run dev`: Starts Vite local dev server (port 5173).
- `npm run build`: Builds production bundle to `dist/`.
- `npm run preview`: Previews built bundle.

## Features
- Accessible healthcare design system with clinical palettes and responsive layout.
- Protected authentication routes with JWT persistence.
- Live dashboard metrics and quick AI search.
- Interactive document viewer (PDF and images) with structured summaries.
- Real-time RAG chat interface with source citations.
- Medication and appointment management forms with filter tabs.
- Chronological health timeline grouped by year.
- Privacy controls with complete account and medical record erasure.
