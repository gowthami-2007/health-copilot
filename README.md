# AI-Powered Personal Health Copilot

Full-stack AI-powered personal health management repository.

The application source code, services, and tests are located inside the [`health-copilot/`](./health-copilot) directory.

### Quick Commands:
```bash
# Seed demo data
npm run seed --prefix health-copilot

# Run full development environment (Frontend on 5173, Backend on 5000)
npm run dev --prefix health-copilot

# Run all 52 tests
npm run test:all --prefix health-copilot
```
